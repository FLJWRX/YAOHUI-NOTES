# 热力学
热力学是研究平衡系统的科学

# 热力学四大定律

| 定律名称                    | 核心表述                                                                                          | 物理意义                                                                 |
| :---------------------- | :-------------------------------------------------------------------------------------------- | :------------------------------------------------------------------- |
| 热力学第零定律<br><br>（热平衡定律）  | 若两个热力学系统均与第三个系统处于热平衡状态，则这两个系统彼此也必然处于热平衡。                                                      | 为**温度**概念提供了严格的热力学定义，是温度测量与热学参比的理论基础。                                |
| 热力学第一定律<br><br>（能量守恒定律） | 热力学系统内能的增量，等于外界向系统传递的热量与外界对系统所做功的总和，公式为：<br><br>ΔU=Q+W<br><br>（符号约定：Q>0 表示系统吸热；W>0 表示外界对系统做功） | 能量守恒与转化定律在热现象领域的具体体现，**从根本上否定了第一类永动机**（不消耗能量却持续对外做功的机器）的存在可能。        |
| 热力学第二定律<br><br>（熵增定律）   | 孤立系统中，自发进行的热力学过程总是朝着熵增大的方向发展，系统的熵永不减少：<br><br>ΔS≥0<br><br>（可逆过程取等号，不可逆过程取大于号）                 | 揭示了宏观热过程的**方向性与不可逆性**，**否定了第二类永动机**（从单一热源吸热并全部转化为功、不产生其他影响的机器）的存在可能。 |
| 热力学第三定律<br><br>（绝对零度定律） | 绝对零度（0 K，即 -273.15 ℃）时，所有纯物质完美晶体的熵值为零；且不可能通过有限的热力学过程将物体冷却到绝对零度。                               | 定义了熵的绝对零点，指明了低温过程的物理极限 —— 绝对零度只能无限趋近，无法通过有限步骤达到。                     |
# 系统（system）、环境（surroundings）、边界（boundary）
## 开放系统（opening）、封闭系统（closed）、孤立系统（isolated）

| 系统类型                              | 与外界的物质交换            | 与外界的能量交换            | 核心定义                                                   | 典型示例                        |
| :-------------------------------- | :------------------ | :------------------ | :----------------------------------------------------- | :-------------------------- |
| **开放系统<br><br>（open system）**     | ✅ 可发生物质交换，物质可自由进出系统 | ✅ 可发生能量交换（热量、功均可传递） | 与外界环境既可以交换能量，也可以交换物质的热力学系统，系统内物质总量可动态变化。               | 敞口烧杯中的水、生命体、化工反应釜           |
| **封闭系统<br><br>（closed system）**   | ❌ 无物质交换，系统内物质总量恒定   | ✅ 可发生能量交换（热量、功均可传递） | 与外界环境仅发生能量交换、完全不发生物质交换的热力学系统，也叫闭合系统。                   | 密封气瓶中的气体、加盖密闭的容器内液体         |
| **孤立系统<br><br>（isolated system）** | ❌ 无物质交换             | ❌ 无能量交换（无热量传递、无做功）  | 与外界环境既不交换物质也不交换能量的热力学系统，是热力学的**理想抽象模型**，现实中不存在严格的孤立系统。 | 理想完全绝热密闭容器；近似场景：保温杯内的水、整个宇宙 |

# 非均相（heterogeneous）、均相（homogeneous）
| 对比维度       | 均相系统（homogeneous）            | 非均相系统（heterogeneous）          |
| :--------- | :--------------------------- | :---------------------------- |
| **核心定义**   | 系统内只含有**一种相**，整体性质处处均匀       | 系统内含有**两种及以上不同的相**，不同相之间有明确分隔 |
| **相界面**    | 不存在宏观相界面                     | 存在清晰的物理相界面，越过界面性质突变           |
| **物质分散程度** | 达到分子 / 原子级别的均匀混合，分散尺度 < 1 nm | 分散相以颗粒、液滴、晶相等形式存在，分散尺度更大，存在相区 |
| **性质特点**   | 任意位置的物理、化学性质完全一致             | 不同相区的密度、组成、折射率等性质存在差异         |
| **典型实例**   | 食盐水溶液、酒精水溶液、纯净空气、纯金属单晶       | 冰水混合物、泥水、泡沫、牛奶、多相合金、油水混合液     |
| **热力学特征**  | 单相系统，可直接应用均相热力学公式分析          | 多相系统，需拆分到每个单相分别分析，存在相平衡问题     |

# 平衡（equilibrium）
系统状态不随**时间**和**空间**的变化而变化

# 广延属性（extensive properties）、强度属性（intensive properties）

广延性质是随系统规模变化而变化的性质，如果系统规模翻倍，这些属性也翻倍。如：体积（V），质量（m）
强度性质不随系统规模变化而变化，与系统规模无关。如：温度（T）、摩尔体积（$\bar{V} = \frac{V}{n}$）

# 对于单组分的均相系统（one component homogeneous system），只需要摩尔（n）+其它2个状态变量（如：温度T、压强p），就可以知道该系统平衡状态时的所有信息！
